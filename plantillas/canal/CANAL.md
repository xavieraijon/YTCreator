## Dónde está cada cosa (rutas relativas a esta carpeta)

| Archivo | Qué es |
|---|---|
| `canal.json` | configuración que leen las herramientas (voz, estilo, tipografías, colores, duraciones, reglas del revisor) |
| `docs/concepto.md` | concepto completo y **reglas de guion y de voz** |
| `docs/progreso.md` | estado, siguiente paso y decisiones del canal |
| `docs/ideas.md` | banco de temas con su semáforo de saturación |
| `docs/historial.md` | vídeos producidos y sus métricas |
| `docs/referentes.md` | canales de referencia |
| `docs/alta_youtube.md` | textos y pasos del alta en YouTube |
| `equipo/` | fichas de los agentes para este canal |
| `marca/` | avatar, banner y vistas previas (`herramientas/marca.py`) |
| `analisis/` | análisis de canales y métricas (capturas de Studio en `analisis/entrada/`) |
| `videos/NNN-slug/` · `videos/SNNN-slug/` | vídeos largos y Shorts de apoyo |
